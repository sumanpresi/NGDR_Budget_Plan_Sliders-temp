The one-minute explanation

Useful as speaking notes.

  1. Think of NGDR's cloud as a rented office building for GSI's data. Instead of buying computers, GSI rents computing space from Amazon Web Services (AWS) and pays a monthly bill.
  2. Today's plan, about ₹1.32 crore a year, keeps the lights on. The website runs and data can be uploaded and downloaded. But there is no spare building if disaster strikes, little room to grow, and no AI.
  3. Every extra rupee should buy something specific. This guide lists 17 improvements in order of importance, with the reason for each.
  5. A sanction is spread over several years, so the yearly amount is what matters. ₹20 crore over 10 years is ₹2 crore a year; the same ₹20 crore over 5 years is ₹4 crore a year and pays for much more.
  6. More money is not automatically better. The amount should be decided by how much NGDR is actually used, which is what GSI has asked BISAG-N to report.

Before asking for more money

Four points that will make any budget proposal stronger, and that others are likely to ask about.

A longer period means less money each year

A fixed sanction divided over more years lowers what can be funded annually. ₹20 crore over 5 years covers roughly twice as much each year as the same amount over 10 years. If the period is long, the sanction has to be larger.

Buy for real use, not for possible use

Computers and bandwidth that sit idle still cost money, and audits will ask why. BISAG-N's figures on how busy the current servers are, how many people use NGDR at once, and how much data moves each day should decide the level chosen.

Committing for 1 to 3 years costs much less

The current estimate uses pay-as-you-go prices, like paying a daily hotel rate for a flat you will live in for years. Committing to 1 or 3 years for the steady part of the workload lowers the price considerably, so the same budget buys more.

Data should stay in India

The prices in the estimate appear to be for AWS's US locations. Government data is generally expected to be stored in India, so the estimate should be re-priced for AWS's Mumbai and Hyderabad locations. Every figure on this page would shift with that.

Money alone doesn't make it work

AI tools, better search and new services also need people to prepare data, check results and run the system. Part of any increase may be better spent on skilled staff at BISAG-N or GSI than on more cloud services.

Word list

The few technical words that come up, in plain language.

Cloud / AWS
Renting computers, storage and internet capacity from a large provider (here, Amazon Web Services) instead of buying and running them yourself.
Server
A computer that runs the website or database for many users at once. In the cloud it is rented by the hour.
Region
A city where AWS has its data centres, such as Mumbai or Hyderabad. Using two regions means having two separate locations.
TB (terabyte)
A measure of data size: 1 TB is 1,024 GB, roughly the space of 250,000 phone photos.
Bandwidth / downloads
How much data travels between NGDR and its users. AWS charges for data going out to users, not for data coming in.
Backup vs disaster recovery
A backup is a spare copy of the files. Disaster recovery is a spare, ready-to-run system, so the website itself can keep working.
GPU
A specialised processor needed to train and run AI models quickly. Ordinary servers are far too slow for this work.
AWS support plan
A paid helpline from AWS. Higher plans answer faster when something breaks.
GST
Goods and Services Tax at 18%, added on top of the AWS bill and support.
